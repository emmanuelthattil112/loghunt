# LogHunt

A daily cybersecurity puzzle. Read simulated Windows-style logs and find the line that shows the attack.

## How to play

1. Pick today's case, or any case in Practice.
2. Read the log.
3. Tap the line that shows the turning point.
4. Submit your answer.
5. Read the explanation.

## Features

- Daily streak: finish today's case to keep your streak going.
- 12 cases covering identity, malware, persistence, lateral movement, credential access, exfiltration, ransomware, web attacks, and more.
- Practice mode with topic, difficulty, and severity filters.
- Friends leaderboard (demo).
- Team challenge (demo).
- Progress and badges.
- Notes for each case, with a download as a .txt file.

## Data

All logs are simulated for training. No real systems or people are involved.

## Saving progress

Progress (streak, scores, notes) is saved in the browser you use. It is not synced between devices yet.

## Run it locally

Open `index.html` in any web browser.
